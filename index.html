Intelligent Auto Planner (Confidential Client Project)

Designed and evolved a production-grade backend scheduling engine integrated into an inspection platform to automate inspector-to-booking allocation.

  1. Version 1 — Heuristic / Greedy Allocation

    • Implemented custom greedy assignment strategy using nearest-resource logic
    • Location-based prioritization using geospatial filtering concepts
    • Re-planning capability for previously approved bookings

  2. Version 2 — Constraint-Based Optimization (Timefold)

    • Integrated Timefold optimization engine for vehicle routing problem (VRP)
    • Improved allocation efficiency through solver-driven optimization

  3. Real-World Constraints

    • Inspection duration
    • Schedule limits
