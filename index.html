About

About Me

I'm a full-stack engineer focused on building production-grade systems that solve real engineering problems.

My work spans backend architecture, API design, distributed services, authentication, scheduling and optimization, and production infrastructure. I enjoy working on problems where reliability, performance, and maintainability matter as much as getting the feature working.

Through projects like MarketMate, the Auto Planner, and Alphabet Music API, I've worked across Spring Boot, Node.js, Angular, NestJS, PostgreSQL, Redis, MongoDB, Docker, and optimization tooling such as Timefold — building systems that go beyond simple CRUD applications.

I'm particularly interested in understanding why a system behaves the way it does, finding the bottleneck or architectural constraint, and then designing a solution that is practical to operate and maintain.

Projects

Intelligent Auto Planner (Confidential Client Project)

Production-grade scheduling engine integrated into an inspection platform to automate inspector-to-booking allocation. The planner evolved from a heuristic allocation strategy into a constraint-based optimization approach using Timefold.

Planning evolution

  1. Version 1 — Heuristic / Greedy Allocation

    • Nearest-resource assignment strategy
    • Location-based prioritization using geospatial filtering
    • Re-planning of previously approved bookings

  2. Version 2 — Constraint-Based Optimization

    • Integrated Timefold for vehicle-routing optimization
    • Solver-driven allocation across scheduling constraints
    • Improved the planning approach by modeling constraints explicitly rather than relying only on heuristic assignment

Real-world constraints

  • Travel time
  • Inspection duration
  • Schedule limits

Distributed Marketplace Platform

Architecture

Core application

  • app.marketmatecloud.in — Angular SSR frontend
  • admin.marketmatecloud.in — Nx-based admin
  • Spring Boot API and Angular SSR frontend share an Nx monorepo
Services
  • Chat service — NestJS real-time messaging
Delivery & infrastructure
  • Custom subdomains for api / app / admin
  • DNS and SSL configuration
  • CORS and CSP configured for production
  • CDN-backed frontend delivery
  • Backend and SSR on Render
