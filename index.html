Production-grade classifieds platform (OLX-style) for buying and selling used goods. Built with a distributed, multi-service architecture and deployed on custom domains with subdomain routing, SSL, and CDN-backed frontends.

  • Spring Boot REST API and Angular SSR app in an Nx monorepo; separate NestJS real-time chat service
  • JWT authentication via httpOnly cookies; PostgreSQL session persistence; Redis validation and caching

  • Backend & SSR on Render; monitoring with Prometheus and Grafana
